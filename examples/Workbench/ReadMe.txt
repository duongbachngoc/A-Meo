QUICK GUIDE - CREATE THE WORKBENCH MODULE

1. Install A Meo first.

2. Copy 2 files:
   - build_project.py
   - WorkbenchV1.1.txt

   into the folder:
   A_Meo_Core

3. Open CMD or PowerShell in the A_Meo_Core folder.

4. Run the command:

   python build_project.py

5. Wait for the program to finish running.

Done. The Workbench module will be created in A Meo.

Then open A Meo -> Scan modules -> Integrate Workbench -> Use it.

No need to edit code, no additional configuration needed.
